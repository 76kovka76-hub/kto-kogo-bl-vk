# Кто кого, бл$дь?! — VK auto publisher

Автоматическая публикация свежих новостей MMA, бокса и борьбы в сообщество VK.

## Настройка

В GitHub → Settings → Secrets and variables → Actions добавьте:
- `VK_ACCESS_TOKEN` — токен VK с правом управления стеной сообщества.
- `VK_GROUP_ID` — `79887216`.

Workflow проверяет RSS-ленты каждые 5 минут круглосуточно. Цель — до 25 публикаций в сутки, равномерно распределённых по всем 24 часам (примерно одна публикация каждые 58 минут). Скрипт дополнительно ограничивает число публикаций 25 в сутки. Если свежей уникальной новости нет, слот пропускается — бот не выдумывает новости.

История ссылок хранится в `post_history.json`, чтобы не повторять одну и ту же новость. В каждой публикации ровно три тематических хэштега; наборы тегов меняются, недавние теги стараются не повторяться.

## Важно про качество пересказа

Скрипт использует заголовок и короткое описание из RSS, очищает их и выбирает краткий фрагмент. Это автоматическое сокращение, а не полноценная генерация редакторского пересказа нейросетью. Рекламные материалы по типовым маркерам отфильтровываются, но автоматический фильтр не может гарантировать распознавание любой скрытой рекламы.

Новости поступают из Google News RSS по запросам о MMA, боксе и борьбе. Перед публикацией проверяется возраст новости (до 48 часов).

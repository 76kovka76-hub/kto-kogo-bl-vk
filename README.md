# Кто кого, бл$дь?! — VK auto publisher

Автоматическая публикация свежих новостей MMA, бокса и борьбы в сообщество VK.

## Настройка

В GitHub → Settings → Secrets and variables → Actions добавьте:
- `VK_ACCESS_TOKEN` — токен VK с правом управления стеной сообщества.
- `VK_GROUP_ID` — `79887216`.

Workflow проверяет RSS-ленты каждые 5 минут и публикует не более одной новости в каждом из 10 дневных слотов (08:00–21:30 по Москве, интервал 90 минут). Если свежей уникальной новости нет, публикация пропускается.

История ссылок хранится в `post_history.json`, чтобы не повторять одну и ту же новость. В публикации добавляются три тематических хэштега и ссылка на источник.

## Важно про качество пересказа

Скрипт использует заголовок и короткое описание из RSS, очищает их и выбирает краткий фрагмент. Это автоматическое сокращение, а не полноценная генерация редакторского пересказа нейросетью: для полностью авторского пересказа понадобится отдельный AI API и его ключ в GitHub Secrets. Рекламные материалы по типовым маркерам отфильтровываются, но автоматический фильтр не может гарантировать распознавание любой скрытой рекламы.

Новости поступают из Google News RSS по запросам о MMA, боксе и борьбе. Перед публикацией проверяется возраст новости (до 48 часов).
